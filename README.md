# GymApp

PWA para iPhone: tracker de gym con rangos por músculo estilo LoL/Valorant, comidas y balance calórico. 100 % local (IndexedDB) y offline.

## Desarrollo

```bash
npm install
npm run dev
npm test
npm run build
```

## Instalar en el iPhone

1. Despliega en Vercel (importa el repo; cada rama tiene su preview HTTPS).
2. Abre la URL en **Safari** → botón Compartir → **Añadir a pantalla de inicio**.

Más detalles en [CLAUDE.md](./CLAUDE.md).
